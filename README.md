## 🌟 الميزات الرئيسية (Key Features)

1. **تصميم Mobile-First فاخر (Luxury Dark & Gold VIP):**
   - واجهة مستخدم شبيهة بالتطبيقات الأصلية (Native Look & Feel) مهيأة للعمل داخل WebView وتطبيقات متجر Google Play.
   - خلفية سوداء كربونية مع بطاقات زجاجية ولمسات ذهبية ملكية.
   - خط **Cairo** العربي العصري.

2. **محرك حجز ذكي ومباشر (Smart Booking Engine):**
   - **الانطلاق:** محصور في الإسكندرية مع تغطية كافة أحيائها (سموحة، المنتزه، محطة الرمل، سيدي جابر، لوران، ميامي، العجمي، كينج مريوط، مطار برج العرب...).
   - **الوجهة:** كافة محافظات مصر ومطاراتها (مطار القاهرة صالات 1/2/3، الساحل الشمالي، العلمين، رأس الحكمة، التجمع، الشيخ زايد، الغردقة، الصعيد...).
   - **نوع الرحلة:** ذهاب فقط أو ذهاب وعودة مع خصم 15% فوري على العودة.
   - **حاسبة المسافة والتسعير اللحظي:** تقدير فوري لزمن الرحلة والمسافة والسعر بالجنيه المصري.
   - **ربط مباشر مع واتساب:** توليد رسالة الحجز التلقائية وتوجيه العميل مباشرة إلى `wa.me/201016518716`.

3. **أسطول سيارات وصول الفعلي (Real Fleet Showcase):**
   - تويوتا كورولا 2024 (Toyota Corolla)
   - هيونداي إلنترا CN7 الفاخرة (Hyundai Elantra CN7)
   - كيا سيراتو جراند (Kia Cerato Grand)
   - مرسيدس E-Class رجال الأعمال (Mercedes-Benz E-Class)
   - مرسيدس S-Class مايباخ VIP (Mercedes-Benz S-Class)
   - هيونداي H1 رويال VIP (Hyundai H1 7-Seater)
   - تويوتا هايس سقف عالي VIP (Toyota HiAce 13-Seater)

4. **لوحة تحكم إدارية كاملة (`/admin`):**
   - حماية برمز PIN (الافتراضي: `2026`).
   - إحصائيات مالية وتشغيلية مباشرة.
   - إدارة وفلترة وبحث الحجوزات.
   - زر محادثة واتساب مباشر للعميل.
   - تصدير البيانات إلى كشف CSV / Excel.
   - إدارة حالة الأسطول.

5. **دعم كامل لثنائية اللغة (Arabic / English):**
   - تحويل فوري لاتجاه الصفحة RTL/LTR وكافة النصوص.

6. **تطبيق PWA أصلي:**
   - شريط تنقل سفلي للهواتف.
   - لافتة تثبيت التطبيق على الشاشة الرئيسية (Add to Home Screen).

## 🛠️ التشغيل والتطوير المحلي

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# تشغيل النسخة الإنتاجية
npm start
```

افتح المتصفح على `http://localhost:3000`
